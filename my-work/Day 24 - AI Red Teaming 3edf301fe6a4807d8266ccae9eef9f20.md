Findings

Misconfiguration discovered: Agent system instructions lacked explicit delimiter isolation, allowing multi-turn delimiter injection payloads to breach the prompt boundary and disclose the mock internal API key.
Root cause: System prompt relied on soft negative guidelines rather than strict isolation of user inputs from operational system instructions.
Remediation: Hardened system prompt with strict delimiter rules (`### USER_INPUT_START ###`) and enabled AI Content Safety Prompt Shielding.
Residual risk: Non-deterministic generative judges may produce occasional false positives/negatives in ASR scoring; manual human review remains mandatory.
